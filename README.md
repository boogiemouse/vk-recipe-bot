# VK-бот для поиска рецептов «Бот рецептов»!

Бэкенд-приложение в формате VK-бота, взаимодействующее с внешним API (TheMealDB). Бот позволяет искать рецепты по названию, получать случайные блюда, а также сохраняет историю запросов пользователей в базу данных.

## Требования к окружению
- Node.js (версия 18 или выше)
- npm
- База данных SQLite (работает автоматически, ничего ставить не нужно)
